# exercicios_beck_aula08

Nesta atividade foi desenvolvida uma API utilizando JavaScript, Node.js e Express, com o objetivo de realizar o gerenciamento de clientes, pedidos, produtos e itens. Foram implementadas as operações de CRUD, permitindo listar, cadastrar, alterar e excluir informações. Também foram criados os arquivos produtos.json e itens.json, juntamente com suas respectivas rotas e controllers.

Durante o desenvolvimento, foram adicionados os relacionamentos entre clientes, pedidos, produtos e itens, utilizando os métodos find e filter para realizar as buscas e associações dos dados. O cálculo do subtotal de cada item foi implementado no controller de itens, enquanto a função calcTotais foi criada para calcular o valor total dos pedidos.

Também foram realizadas alterações no arquivo pedidos.json conforme solicitado no enunciado e removida a função de cálculo de subtotais que anteriormente estava no controller de pedidos. Ao final, todas as rotas foram testadas utilizando o Thunder Client, verificando o funcionamento das requisições
